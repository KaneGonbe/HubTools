# Kakeibo - 家計簿アプリ（フロントエンド）

シンプルで使いやすい家計簿管理アプリケーションのフロントエンド部分です。

## 主な機能

### Phase 1: 基本機能
- ✅ ユーザー登録・ログイン
- ✅ グループ作成・参加
- ✅ 収支データの登録（CRUD）
- ✅ データ一覧表示
- ✅ カテゴリ管理

### Phase 2: 集計機能（実装予定）
- 🚧 指定期間での集計
- 🚧 カテゴリ別集計
- 🚧 グループ別集計

## 技術スタック

- **フロントエンド**: React 18
- **ビルドツール**: Vite
- **スタイリング**: CSS-in-JS（インラインスタイル）
- **アイコン**: Lucide React
- **HTTP クライアント**: Axios

## セットアップ

### 1. 依存関係のインストール

```bash
npm install
```

### 2. 環境変数の設定

`.env.example` ファイルを `.env` にコピーし、必要に応じて編集します。

```bash
cp .env.example .env
```

### 3. 開発サーバーの起動

```bash
npm run dev
```

アプリケーションは `http://localhost:3000` で起動します。

### 4. ビルド

本番用ビルドを作成する場合:

```bash
npm run build
```

ビルドされたファイルは `dist` ディレクトリに生成されます。

### 5. プレビュー

ビルドしたアプリケーションをプレビューする場合:

```bash
npm run preview
```

## 主要コンポーネント

### App.jsx
認証状態を管理し、未認証時は `AuthPage`、認証済みは `KakeiboApp` を表示します。

### AuthPage.jsx
ユーザー登録とログイン機能を提供します。

### kakeibo-app.jsx
家計簿のメイン機能を提供します:
- ダッシュボード（収支サマリー、カテゴリ別内訳、最近の取引）
- 取引履歴（フィルタリング機能付き）
- グループ管理

### api.js
バックエンドAPIとの通信を管理します:
- 認証API（登録、ログイン、プロフィール取得）
- トランザクションAPI（CRUD、集計）
- カテゴリAPI（CRUD）
- グループAPI（CRUD、メンバー管理）

## バックエンドとの連携

このフロントエンドアプリケーションは、別途作成するNode.js + Express + PostgreSQLバックエンドと連携します。

デフォルトでは `http://localhost:5000/api` をAPIエンドポイントとして使用します。

## デザイン仕様

- **カラースキーム**: グリーン系（#10b981）をメインカラーに使用
- **レスポンシブ**: モバイルファーストデザイン
- **アニメーション**: スムーズなトランジションとホバーエフェクト
